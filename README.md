# Automation Hub – Ayesha Abed Foundation (Gorpara)

A centralized portal showcasing internal automation projects developed for Ayesha Abed Foundation (AAF), Gorpara. These projects leverage Google Apps Script and modern web interfaces to streamline operational workflows, eliminate manual errors, and replace paper-based systems.

## Live Portals

The hub provides quick access to the following automation tools:

1.  **Section Wise Daily Per Hour Production Report**
    *   Tracks hourly production output section-by-section.
    *   Auto-generates structured daily reports.
2.  **Paperless Production Planning Portal**
    *   Digital allocation, scheduling, and tracking of production tasks.
3.  **Snack's Bill Generator**
    *   Automates canteen refreshment claims and bill formatting.
4.  **Travel Bill Generator**
    *   Simplifies travel expense claims with auto-calculation and standardized formatting.
5.  **Attendance Bonus Generator**
    *   Generates attendance bonus based on employee attendance data with accurate calculations.

## Tech Stack

*   **Frontend:** HTML5, CSS3 (Modern Design System), Vanilla JavaScript
*   **Animations:** Intersection Observer API for scroll-triggered effects, smooth transitions
*   **Backend (Automation Logic):** Google Apps Script (GAS)
*   **Typography:** Playfair Display & DM Sans

### Key UI Features
- **Light cream background** with subtle noise texture overlay
- **White cards** with soft shadows and rounded borders
- **5-color accent system** - each portal card has a unique accent color
- **Fade-up animations** on scroll via IntersectionObserver
- **Sticky glass navigation** with blur effect
- **Responsive grid** layout adapting from 1 to 3 columns

### Typography
- **Headings:** Playfair Display (700, 800)
- **Body:** DM Sans (300-600)

## Philosophy

These projects prove that expensive enterprise software isn't always necessary for operational efficiency. Smart scripts and clean, accessible UIs can solve significant bottlenecks in decentralized environments.

## Features

- **Zero Configuration:** Open `index.html` directly in a browser - no build step required
- **Fully Responsive:** Optimized for mobile, tablet, and desktop
- **Accessible:** Semantic HTML, ARIA labels, keyboard navigation
- **Performance Optimized:** Minimal dependencies, lazy animations, optimized loading
- **Light Theme:** Clean cream/white palette with colorful accents
